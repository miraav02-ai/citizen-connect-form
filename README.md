# Citizen Connect Form

Buat frontend prototype untuk "Form Pengaduan Masyarakat".

Fokus hanya pada UI/UX frontend. Jangan membuat backend, database, API, chatbot, login, atau integrasi WhatsApp.

Buat desain yang modern, clean, profesional, dan cocok untuk layanan publik. Responsive terutama untuk mobile. Gunakan layout yang sederhana, nyaman, dan tidak terlalu ramai.

Buat 4-step form:

1. Data Pelapor

2. Kategori & Jenis Masalah

3. Detail Pengaduan

4. Konfirmasi

Gunakan progress indicator untuk menunjukkan posisi pengguna:

Data Pelapor → Detail → Keterangan → Konfirmasi

Pastikan seluruh step berada dalam satu flow dan data form tetap tersimpan ketika berpindah halaman.

Untuk sekarang, buat struktur dan visual utama terlebih dahulu dengan dummy data.
